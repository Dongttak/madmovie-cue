# CUE — 매드무비 편집 도구 · 공개 알파

**버전: 0.10.0-alpha.6**

음악의 파형·박자·에너지 변화를 확인하고, 사용자가 고른 게임 영상으로 편집을 시험하는 오픈소스 프로젝트입니다. CUE 작성 코드는 [MIT](LICENSE) 라이선스입니다. API·편집 계획 형식과 출력 품질은 알파 단계에서 바뀔 수 있습니다.

**교전의 흐름과 표적 가독성을 우선합니다. 모든 킬에 슬로우를 넣지 않습니다.**
자동 분석은 후보를 제시하고, 최종 타이밍은 사용자가 보고 듣고 보정합니다.

## 현재 범위

- 로컬 음원 열기, 파형·재생 위치·BPM·타격 후보 표시와 수동 보정
- 에너지 기준 음악 구간 추천, 구간 선택과 JSON 내보내기
- 브라우저에서 사용자 음원·영상으로 로컬 합성
- Python·FFmpeg의 교전 유지 / 박자 배치 렌더링 코드와 합성 자료 기반 테스트
- EffectCraft CLI용 실험적 효과 도구. 상용 Twixtor나 After Effects 플러그인은 포함하지 않음

자동 킬 인식, 레퍼런스 수준의 자동 연출, 후렴 분류, AI 기반 편집 완성도를 보장하지 않습니다.
비공개 실험 영상과 수동 편집 실험은 공개 제품 기능과 구분합니다.

## 실행

Python 3로 정적 앱을 실행합니다. 로컬 음원 분석에는 npm 패키지나 서버 업로드가 필요 없습니다.

```bash
python3 -m http.server 5173 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. Node.js 20 이상이면 `npm start`도 가능합니다.
사용 권한이 있는 파일을 직접 선택하세요. 브라우저 코덱 지원과 메모리에 따라 처리 가능한 파일은 달라집니다.

### 음악 공급 연동은 기본 비활성

공개 소스에는 음원, NCS 공급 카탈로그, 선수 영상, 레퍼런스 영상, 음악이 포함된 결과물을 넣지 않습니다.
카탈로그가 없는 API 서버는 빈 곡 목록을 반환하며 외부 음악을 가져올 수 없습니다.
기존 제공곡 패널은 소스에 남아 있지만 공개 알파의 기본 사용 경로는 로컬 파일입니다.

제공곡 기능은 권한을 별도로 확인한 운영자가 로컬 카탈로그를 준비할 때만 활성화됩니다.
공식 소스에 접근할 수 있다는 사실이나 NCS의 창작자 영상 정책만으로 플랫폼 공급 권한을 확보했다고 보지 않습니다.
음악만 내려받는 API는 없습니다. 자세한 사항은 [외부 구성 요소·미디어 고지](THIRD_PARTY_NOTICES.md)를 참고하세요.

## 기술 선택

| 영역 | 알파에서 사용하는 것 | 선택 이유 |
| --- | --- | --- |
| UI | Vanilla JS ESM, CSS, Lucide SVG, Radix Colors | 현재 UI와 접근성·재생 코드를 유지하며 편집 실험에 집중 |
| 타입 | TypeScript + JSDoc 점진 검사 | 파형·데모·구간 추천 모듈부터 strict 검사. 전체 TS 전환은 아님 |
| 그래픽·오디오 | Canvas, Web Audio, 브라우저 미디어 API | 파형·로컬 재생·합성에 직접 필요한 기능 |
| 서버 렌더 | Python 표준 라이브러리, 별도 FFmpeg / FFprobe | 기존 검증·타임라인·음성 믹싱 재사용 |
| 고급 합성 | 별도 EffectCraft CLI, 선택 사항 | 레이어·마스크·키프레임 실험 |
| 통신·상태 | fetch, 모듈 내부 상태 | 현재 규모에서 별도 요청·전역 상태 패키지 불필요 |
| 패키지 | npm + package-lock.json | 기존 환경·잠금 파일 유지; `npm ci`로 재현 |
| 검증 | Node test runner, Python unittest, Playwright + axe | 기존 단위·실제 렌더·브라우저 검증 유지 |
| 협업 | GitHub Issues + PR, Discord 논의 | 이슈를 단일 작업 기록으로 유지 |

React + TypeScript + Vite는 타임라인 UI를 재구성할 필요가 생길 때 검토합니다.
그때부터 새 UI 단위로 이전하고 알고리즘·서버 코드는 재사용합니다. 지금은 React/Next.js,
Tailwind/shadcn, Zustand/TanStack Query, Axios, 별도 번들러·트랜스파일러를 추가하지 않습니다.
분석 중 UI 정지가 확인되면 Web Worker를 먼저 검토합니다. WebRTC·WebSocket·3D 렌더러는 현재 범위 밖입니다.
ESLint/Prettier는 포맷 규칙을 팀이 정할 때 별도 변경으로 도입하고 기존 파일 전체를 일괄 재작성하지 않습니다.
외부 오류 추적 서비스는 영상·파일명·사용자 정보 수집 정책을 정한 후 검토합니다.

TypeScript로 기존 JavaScript를 검사하는 방식은 [공식 JS 검사 문서](https://www.typescriptlang.org/docs/handbook/type-checking-javascript-files.html)에 따릅니다.

## 개발 확인 — 수동 실행

```bash
npm ci
npm run verify
npm run test:public
npm run test:security
```

FFmpeg / FFprobe와 Node.js가 설치돼 있다면 서버 합성을 검사합니다.
테스트는 영상·음을 자체 생성하고 외부 음악 다운로드를 모의합니다. 비공개 카탈로그가 없어도 실행됩니다.

```bash
npm run test:server
npx playwright install chromium
npx playwright test
```

Git에 추가한 공개 후보를 검사합니다. GitHub에 게시하거나 서버를 배포하는 명령이 아닙니다.

```bash
git add .
npm run check:public
```

`check:public`은 Git 인덱스에서 미디어·비공개 운영 파일·일부 알려진 비밀값 패턴을 검사합니다.
완전한 보안 감사나 권리 확인을 대신하지 않습니다. 원본 자료는 로컬에 그대로 보관됩니다.

외부 기여가 늘면 PR의 타입·단위 검사를 실행하는 작은 CI부터 검토하고, 자동 배포는 별도로 결정합니다.

알파의 다음 우선순위:

1. 원속도 / 선택적 속도 조절을 비교하며 교전 흐름·시선·음악·여운 평가
2. 비공개 실험에서 검증한 속도 곡선·선택적 강조를 제품의 편집 계획으로 연결
3. 사용자 소유 영상·음원으로 재현 가능한 예제와 가이드 준비
4. 타임라인 상태·실행 취소 요구가 커질 때 UI·상태 모델 재검토

`media.py`는 API의 FFmpeg/FFprobe 실행 경로와 선택적 격리를 한 곳에서 관리합니다.
`CUE_MEDIA_BIN`·`CUE_BWRAP` 설정 및 실제 격리 검증 명령은 [RUNTIME.md](RUNTIME.md)에 있습니다.

`dist/`는 현재 직접 관리하는 브라우저 소스입니다. 번들러의 자동 생성 폴더가 아닙니다.
`tests/`는 합성 자료 테스트, `ops/`는 공개 가능한 분석·효과·검사 도구입니다.
기존 서버의 운영 기록·개인 자료는 공개 소스에서 제외합니다.

서버 렌더링은 HTTPS와 알파 계정을 사용하며, 시간당 사용량을 제한합니다. 로컬 분석은 로그인 없이 사용할 수 있습니다. 설정과 제한은 [ACCESS.md](ACCESS.md)를 참고하세요.

### 선택적 강조와 비교

교전 영상을 추가하고 시작·끝을 고른 뒤, 미리보기 또는 타임라인에서 중요한 순간 하나를 선택하세요. ‘현재 위치를 강조’로 짧은 줌 또는 부드러운 슬로모션을 지정합니다. 강조 시간은 원본 초로 수정하거나 삭제할 수 있고, 클립당 한 지점만 사용합니다. 시작·끝에는 각각 0.3초 여유가 필요합니다.

‘선택 구간 확인’을 누르면 실제 음악의 RMS 에너지 메타데이터를 파형으로 표시합니다. 원본 미리보기에는 게임 소리만 재생되며, 음악은 렌더링한 완성본에서 확인합니다. 브라우저에 NCS 음원 파일을 제공하지 않습니다. 기본본과 강조본을 각각 만들면 같은 원본 순간을 기준으로 전환해 비교하고 선택한 MP4를 저장할 수 있습니다. 두 번 만들기는 렌더 할당량 두 회를 사용합니다.

줌은 중심 기준 최대 8%이며 선택 순간에만 적용됩니다. 슬로모션은 0.6초 원본 구간에서 1배→최저 0.5배→1배로 연속적으로 변하고, 출력 길이는 0.3초 늘어납니다. 원본 교전 구간을 생략하지 않으며 음악 속도는 그대로 유지합니다. 게임 소리는 같은 시간 변화를 따라가므로 피치도 바뀝니다. 이 버전은 원본 프레임을 재배치하며 광학 흐름/Twixtor 보간이나 장면 자동 인식은 사용하지 않습니다. 음악이 부족하거나 결과가 60초를 넘으면 자동으로 자르지 않고 수정을 요청합니다.

### 작업별 화면

기본 화면은 ‘교전 편집’입니다. ‘음원 분석’에서 로컬 음원 파형·박자 보정·브라우저 합성을 사용하고, ‘빠른 쇼츠’에서는 NCS 곡과 영상 하나를 합성합니다. 탭을 옮겨도 고른 파일과 편집 상태는 유지됩니다. 키보드 방향키·Home·End로 작업 탭을 이동할 수 있습니다. 영상 작업 중에는 완료하거나 취소한 뒤 탭을 바꾸도록 안내합니다.

교전 편집은 음악·출력 설정과 영상·타임라인·내보내기를 나누어 보여줍니다. 모바일에서는 영상 추가를 먼저 배치합니다. 음악 목록 연결에 실패해도 영상 미리보기·구간 선택·강조 지점 수정은 가능하고, 서버 렌더는 유효한 음악과 구간 확인이 필요합니다.

Lucide 아이콘과 Radix Colors의 필요한 정적 파일만 배포하며 외부 CDN을 호출하지 않습니다. 버전·무결성·파일 해시는 `dist/vendor/SOURCES.json`에, 각 라이선스는 같은 디렉터리에 보관합니다. `npx playwright test`는 기존 편집 흐름과 탭 이동·상태 유지·반응형 폭 및 axe 자동 접근성 검사를 포함합니다. 자동 검사 통과는 전체 접근성 인증이나 실제 기기 검증을 뜻하지 않습니다.

### 공식 미리듣기

교전 편집과 빠른 쇼츠의 음악 선택에서 ‘시작 위치에서 미리듣기’를 누르면 YouTube 공식 영상 플레이어를 엽니다. 확인된 NCS 공식 페이지의 Watch 링크와 공식 Linkfire 페이지에서 얻은 영상 ID만 사용합니다. 공급 카탈로그의 선택적 `youtubeId`는 공개 메타데이터로 전달하지만 음원 URL은 전달하지 않습니다. `python3 ops/add_ncs_previews.py`는 기존 비공개 카탈로그에 공식 영상 ID를 보완하며 음원·영상 미디어를 다운로드하지 않습니다. 확인하지 못한 곡은 공식 페이지 링크로 안내합니다.

버튼을 누르기 전에는 외부 플레이어를 불러오지 않습니다. 누르면 [YouTube privacy-enhanced embed](https://support.google.com/youtube/answer/171780?hl=en)를 사용하고, 곡 변경·닫기·작업 화면 전환·영상 만들기 시 플레이어를 제거합니다. 입력한 음악 시작 위치를 정수 초로 전달하며, 공식 영상과 렌더 음원의 타이밍은 다를 수 있습니다. 별도 파일 다운로드나 프록시 스트리밍은 제공하지 않습니다.

배포 CSP는 `frame-src https://www.youtube-nocookie.com`을 허용해야 합니다(`ops/nginx.example.conf`). iframe의 `referrerpolicy="strict-origin-when-cross-origin"`과 origin 매개변수로 플레이어 식별 정보를 제공합니다. YouTube의 로그인·봇 확인 또는 영상별 재생 제한이 나타나면 공식 페이지에서 확인해야 합니다. 서버 자동 브라우저에서는 iframe 200 응답과 봇 확인 화면을 확인했으며 실제 청취 완료를 검증한 것은 아닙니다.
